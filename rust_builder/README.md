# VolTrike Rust build glue

This directory was generated by `flutter_rust_bridge` 2.12.0 and then
intentionally patched for this Android-first pilot. Do not delete it or rerun
FRB `integrate` without reviewing and reapplying these project requirements:

- Android-only Flutter plugin registration.
- AGP 8.13.2, compile SDK 36, Java 17, and min SDK 24.
- ARMv7, ARM64, and x86_64 targets, with legacy 32-bit x86 excluded.
- The exact channel from `rust/rust-toolchain.toml` and Cargo `--locked`.
- 16 KB linker alignment for ARM64 and x86_64.

`flutter_rust_bridge_codegen generate` is the normal binding refresh command
and does not replace this directory.

After changing the bridge or build glue, verify:

1. Rust format, tests, and Clippy.
2. Flutter tests and analysis.
3. A physical-device native integration test.
4. A universal release APK containing all three intended Rust libraries.
5. ARM64/x86_64 ELF `PT_LOAD` alignment of at least `0x4000`.
6. `zipalign -c -P 16 4` against the release APK.

Flutter integration tests can leave an ignored
`android/app/src/main/java/io/flutter/plugins/GeneratedPluginRegistrant.java`
that includes the test plugin. Remove that generated file (or run the normal
clean release workflow) before a production-scope release build.
